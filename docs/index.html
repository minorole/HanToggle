Local conversion

Conversion happens on your Mac. No network conversion, no servers, no text upload.

Clipboard protected

The replacement flow is designed to restore your clipboard after conversion.

macOS 13+

Lightweight and native, with universal releases for Apple Silicon and Intel Macs.

Get running

Three steps, then one shortcut.

1

Install

Download the notarized DMG from GitHub Releases and drag HanToggle to Applications.

2

Enable Accessibility

Allow HanToggle in System Settings so it can replace selected text in other apps.

3

Toggle text

Select Chinese text and press your configured hotkey to switch scripts in place.

Private by design

No analytics. No telemetry. No server conversion.

HanToggle treats selected text and clipboard contents as private user data. It does not log, store, or transmit selected text, clipboard contents, or converted text.

Open source

A small utility built in the open.

HanToggle is MIT licensed. The conversion library, CLI harness, macOS app target, tests, and release scripts are available on GitHub.
