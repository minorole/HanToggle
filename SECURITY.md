# Security Policy

HanToggle converts selected text locally. Selected text and clipboard contents are private user data.

## Reporting Security Issues

Please report security issues through GitHub Security Advisories if available, or by opening an issue with only non-sensitive reproduction details.

Do not include private selected text, clipboard contents, credentials, tokens, personal data, or secret files in reports. Use short made-up examples when a text sample is needed.

## Scope

Security-sensitive areas include:

- Selected text and clipboard handling
- Accessibility permission behavior
- Global hotkey handling
- Release signing and notarization scripts
- Any future code that could persist or transmit user data
